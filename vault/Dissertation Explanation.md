The aim of this is to provide a way that we can use machine learning on a custom defined DSL to find better optimised solutions to a given problem. 

The best example of this that I can think of to help describe is like solving a Rubik's cube, this is because there are a range of heuristics that people use to solve a Rubik's cube with some being faster but more complex and others being slower but simpler. So the ultimate goal of this dissertation is to be able to have an algorithm that can use machine learning to find the 'best' heuristic for solving a given problem.
